# Local AI inference runtimes and libraries — 2026-09-24

**Scope:** 63 major examples across desktop engines, throughput servers, model libraries, creative/audio workflows and edge runtimes. This is a maintained snapshot, not a claim to enumerate every fork, version, extension or hosted API. Helix integration is a future design decision; inclusion does not mean an adapter exists.

**How to read:** “Files/formats” describes direct input or a clearly marked conversion path. “Example model families” are examples only; formats alone do not guarantee architectural or tokenizer compatibility. GGUF is a checkpoint container; GPTQ/AWQ/EXL2/EXL3 are quantization schemes/formats; Safetensors stores tensors, and ONNX/IR/PTE/TensorRT engines represent exported computation. A Hugging Face repository can contain several of these formats.

**Math/science/coding:** no inference runtime is intrinsically a math or science expert. Accuracy follows the actual model checkpoint, prompting and evaluation; a faster server can change latency and throughput. **Video:** a pipeline can generate video only with a supported video model and execution path. A VLM that reads video is not necessarily a video generator.

**Your Windows 11 + dual RTX 3090:** prioritize llama.cpp GGUF, Ollama, LM Studio, Radium, Transformers/Diffusers, ONNX Runtime and ComfyUI. vLLM is officially Linux-only and needs WSL on Windows; TensorRT-LLM is Linux-first. Two 24 GB cards do not automatically provide a single 48 GB allocation; check tensor split/offload/pipeline support per runtime.

## Format quick key

| Name | Meaning |
| --- | --- |
| GGUF | llama.cpp-family model container, often with quantized weights. |
| Safetensors | Tensor storage used by many Hugging Face/PyTorch/MLX models; needs matching config and code. |
| PyTorch .pt/.pth/.bin | Serialized weights or program, depending on producer; often requires model code. |
| GPTQ / AWQ | Quantized weight layouts; support depends on loader, model and GPU. |
| EXL2 / EXL3 | ExLlama-specific quantization ecosystems; not generic GGUF. |
| ONNX | Exported model computation graph; can have external tensor data. |
| OpenVINO IR | OpenVINO XML graph plus BIN weights. |
| TensorRT engine | Compiled engine, usually .plan, hardware/build dependent. |
| MLX | Apple Silicon model layout, commonly Safetensors plus model config. |
| MLC / Core ML / PTE / TFLite / MNN / ncnn | Converted or compiled formats for their corresponding runtimes. |

## Use in Helix

Monitor a **specific running engine**, not just a file extension. An adapter should report runtime/backend, model ID and revision, format, actual host/device, local endpoint, supported telemetry, and whether data is per-request or aggregate. Wrappers such as LocalAI, BentoML, Dynamo or ComfyUI require backend-aware attribution to avoid double counting. Treat benchmark-driven tuning as a separate opt-in workflow.
